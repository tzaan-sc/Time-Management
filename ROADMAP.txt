═════════════════════════════════════════════════════════════════════════════════

Nguyên tắc cốt lõi:
- Giai đoạn 1: Desktop MVP KHÔNG có Java backend (SQLite local only)
- Giai đoạn 2: Mobile từ codebase hiện tại (không thay đổi kiến trúc)
- Giai đoạn 3: Cloud + Java Backend (Spring Boot + PostgreSQL)

Kiến trúc mở rộng:
Giai đoạn 1-2:
  Flutter UI → State Management → Repository → Data Source → SQLite

Giai đoạn 3:
  Flutter UI → State Management → Repository → Local Data Source (SQLite)
                                      → Remote Data Source (Spring Boot API)
                                      → PostgreSQL

PHẦN 1: CẤU HÌNH MÔI TRƯỜNG (Environment Setup)
═════════════════════════════════════════════════════════════════════════════════

[ ] Bước 1.1: Cài đặt Flutter SDK
  - Download Flutter SDK từ https://flutter.dev/docs/get-started/install/windows
  - Extract vào thư mục (ví dụ: C:\flutter)
  - Thêm Flutter vào PATH: C:\flutter\bin
  - Chạy lệnh kiểm tra: flutter doctor
  - Đảm bảo Flutter doctor không có lỗi

[ ] Bước 1.2: Cài đặt Dart SDK
  - Dart SDK đi kèm với Flutter (không cần cài riêng)
  - Kiểm tra: dart --version

[ ] Bước 1.3: Cài đặt Visual Studio (cho Windows desktop)
  - Cài Visual Studio Community 2022
  - Chọn workload: "Desktop development with C++"
  - Đảm bảo có MSVC compiler để build Windows

[ ] Bước 1.4: Cài đặt Android Studio (tùy chọn, cho sau này)
  - Download từ https://developer.android.com/studio
  - Cài đặt Android SDK
  - Cài đặt Android Virtual Device (AVD)

[ ] Bước 1.5: Cài đặt IDE
  - Option A: VS Code + Flutter extension
  - Option B: Android Studio + Flutter plugin
  - Option C: IntelliJ IDEA + Flutter plugin

[ ] Bước 1.6: Kiểm tra môi trường
  - Chạy: flutter doctor -v
  - Đảm bảo tất cả checkmarks xanh
  - Fix các warning nếu có
